# Snahasish Paul Tonmoy — Portfolio

My personal portfolio featuring projects, technical skills, learning interests, and certificates.

## Live website

https://snahasishpaul7-design.github.io/my-portfolio/

## Add a certificate

Use **Add certificate** on the portfolio to add a PDF or image with a title and short explanation. Added certificates are saved in that browser on that device. To publish a certificate for everyone, add its file under `assets/certificates/` and add its entry in `script.js`.

## Add future GitHub projects

The portfolio checks the public repositories for `snahasishpaul7-design` when the page opens and adds new, non-fork repositories automatically. Add a short description in a repository's **About** section so visitors know what it covers.
