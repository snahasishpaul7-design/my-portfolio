# Snahasish Paul Tonmoy — Portfolio

A responsive personal portfolio with project links, contact details, skill highlights, and visible certificate previews.

## Visit the live site

https://snahasishpaul7-design.github.io/my-portfolio/

## Add certificates

Use **Add certificate** in the Certificates section to add a PDF or image, plus its title and a short explanation. Added certificates are stored in the browser on that device. To publish a new certificate so everyone can see it, add its file to `assets/certificates/` and add its entry in `script.js`.

## Add future GitHub projects

The portfolio checks the public repositories for `snahasishpaul7-design` when the page opens and adds new, non-fork repositories automatically. Add a short description in the repository's **About** section for a useful project card.
